# Reporting a security problem

If you find a weakness in the encryption of europe.social direct messages, please report it privately:
use **[Report a vulnerability](../../security/advisories/new)** on this repository (GitHub private vulnerability
reporting). Only the maintainers see the report. If you have no GitHub account, write to contact@europe.social and
say in the subject that it is a security report; do not put details of an unfixed problem in a public issue.

Please include what you found, how to reproduce it, and what an attacker could do with it. We answer every report,
fix confirmed problems as fast as we can, and credit you in the advisory if you want.

In scope: the code in this repository, the protocol described in [PROTOCOL.md](PROTOCOL.md), and any difference
between this repository and what europe.social delivers or stores (see [SERVER.md](SERVER.md)). The limitations
listed in [PROTOCOL.md, section 9](PROTOCOL.md#9-known-limitations) are known; new ways to exploit them are still
welcome.

Please do not test against other people's accounts or data on europe.social.
